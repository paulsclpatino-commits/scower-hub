scower. Find any fit for less
Demo mode: every search shows the same sample listings for a Supreme hoodie, whatever photo you upload, and the links open store search pages. To search for your own items, add API keys and start Scower with start.cmd (or npm start).

Drop a pic. Get the lowest price.

Upload a photo of a piece of clothing. Scower finds that exact item on resale sites and stores, then lists every result from cheapest to most expensive, with sizes and links straight to each listing.

Almost ready: no search sources are connected.

Add API keys to the .env settings file in the Scower folder (on Windows, double-click edit-settings.cmd to open it), then restart Scower:

  • ANTHROPIC_API_KEY: identifies the exact item in your photo
  • SERPAPI_KEY: Google Lens and Google Shopping, which cover Grailed, StockX, Depop, Poshmark and many more
  • EBAY_CLIENT_ID / EBAY_CLIENT_SECRET: eBay photo and keyword search

Want to see how it works first? Double-click start-demo.cmd (Windows) or run npm run demo.
